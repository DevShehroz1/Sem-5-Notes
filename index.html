01 What is Flutter?

Flutter is a tool that allows you to build Native Cross-Platform (iOS, Android) apps using one Programming Language and one Codebase.

More formally, Flutter is Google's open-source UI toolkit for building beautiful, natively compiled applications for mobile, web, desktop, and embedded devices from a single codebase.

Native

  • Built with platform-specific languages — Swift for iOS, Java/Kotlin for Android
  • Tight integration with platform hardware & features
  • Smooth performance and full device capability access

Cross-Platform

  • One codebase runs on multiple platforms
  • Saves time & resources
  • Flutter uses Dart, compiled to native code for each platform
In Easy Words Flutter is like a Universal Charger — one thing that works everywhere. It acts as a translator that knows Java/Kotlin (Android) and Swift (iOS), so you write once in Dart and it speaks to both.

Programming Language vs Codebase

Programming Language

The set of rules you use to tell the computer what to build. Like specific instructions: "Dig a moat here, build a tall tower there." It's the language the computer understands.

Codebase

Your entire plan — like a kitchen book with all recipes. It holds all the code for your app in one place, organized in order.

02 Major Components of Flutter

Flutter = two major things:

Flutter SDK

  • Collection of tools to build apps for Android & iOS in one codebase
  • Set of instructions that aid application development
  • Includes tools for converting Dart code to native machine code
  • Works for both iOS and Android

Flutter Framework

  • Provides predefined widgets & widget library
  • Utility functions & packages
  • Set of reusable UI components (buttons, text inputs, sliders, etc.)
  • Components can be customized according to purpose

05 VAR Type Variable

The var keyword declares variables without explicitly specifying their type. Dart infers the type from the value assigned.

dynamic vs var

  • var without initialization → type can change during execution.
  • var initialized with int → type cannot change.

01 What is Machine Learning?

Machine Learning (ML) is defined as a discipline of Artificial Intelligence (AI) that provides machines the ability to automatically learn from data and past experiences to identify patterns and make predictions with minimal human intervention.

Machine Learning is a branch of computer science where you use statistical techniques to find patterns in your data.

ML vs Deep Learning In ML you have to create features manually. In Deep Learning (DL) it automatically creates features.

02 Applications of Machine Learning

Computational Finance
Credit scoring, algorithmic trading
Computer Vision
Facial recognition, motion tracking, object detection
Computational Biology
DNA sequencing, brain tumor detection, drug discovery
Automotive & Aerospace
Predictive maintenance in manufacturing
Natural Language Processing
Voice recognition, language translation
Generative AI
ChatGPT, self-driving cars, credit scoring

03 How ML is Superior?

By identifying patterns in vast datasets, ML algorithms can make predictions or decisions without being explicitly programmed to perform specific tasks. This distinguishes ML from traditional software, where outcomes are predetermined by a set of rules.

04 AI vs Machine Learning vs Deep Learning

Artificial Intelligence

  • The broadest concept
  • Machines capable of performing tasks in a way we would consider "smart"
  • Programs with the ability to learn and reason like humans

Machine Learning

  • A subset of AI
  • Algorithms enabling computers to learn from and make data-based decisions
  • Example: clustering customers based on purchasing behaviors
Deep Learning A subset of ML that uses neural networks with many layers (hence "deep") to analyze patterns in data, mimicking the human brain's approach to learning. Deep learning is responsible for ChatGPT and self-driving cars. It is a class of algorithms inspired by biological neurons.

The relationship forms a nested hierarchy: AI > ML > Deep Learning > Data Science. Each is a subset of the one above it.

05 How Does Machine Learning Work?

1
Collect Training Data — historical data with known inputs and outputs.
2
Train the ML Algorithm — the algorithm is molded on the training dataset to create a model.
3
Feed New Input Data into the trained ML algorithm.
4
The model produces a Prediction.
5
Check Accuracy — if acceptable, deploy as a successful model; if unacceptable, re-train with augmented data.

06 Types of Machine Learning

Supervised Learning

  • Trained on labeled datasets
  • Inputs and outputs are known
  • Goal: map input variable to output variable

Unsupervised Learning

  • No labeled data
  • Finds hidden patterns or groupings
  • Example: customer segmentation

Semi-Supervised Learning

  • Mix of labeled and unlabeled data
  • Cheaper to acquire than fully labeled data

Reinforcement Learning

  • Agent learns by interacting with environment
  • Receives rewards/penalties
  • Example: game playing AI

07 Deep Learning vs Machine Learning

FactorMachine LearningDeep Learning
Data Dependency Works well with less data. Performance plateaus as data increases. Data hungry. Performance keeps improving as more data is added.
Hardware Dependency Can run on CPU without issues. Requires GPU (Graphical Processing Unit) due to heavy matrix multiplication.
Training Time Training is relatively fast. Training time is high — can take weeks or months.
Feature Selection You must manually create features (e.g., number of courses, marks in semesters). DL models extract features automatically from raw data.

08 Supervised Machine Learning

A paradigm in ML where algorithms learn the relationships between input data and outcomes. The algorithm is trained on labeled datasets and enabled to predict outputs based on the provided training. The primary objective: map the input variable to the output variable.

Input: IQ, CGPA    Output: Placement (Yes / No)

09 Types of Supervised ML

Regression

  • Target variable is continuous (numerical)
  • Predicts a quantity
  • Examples: house price, salary, marks

Classification

  • Target variable is categorical
  • Predicts a class/label
  • Examples: spam/not spam, pass/fail, Yes/No

01 Introduction to Regression Techniques

Multiple Linear Regression

  • Dependent (output) variable is continuous
  • Depends on two or more independent (input) variables
  • Models how changes in multiple features affect a numerical outcome
  • Example: predicting house prices from area, rooms, and location

Logistic Regression

  • Used for classification problems
  • Dependent variable is categorical / binary (Yes/No, 0/1)
  • Estimates the probability that an input belongs to a class
  • Applications: disease prediction, spam detection, customer churn

02 Example 1 — Multiple Linear Regression: Marks Prediction

import pandas as pd
from sklearn.linear_model import LinearRegression

04 Example 3 — Logistic Regression: Pass / Fail Classification

from sklearn.linear_model import LogisticRegression
