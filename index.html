01 What is Flutter?

Flutter is a tool that allows you to build Native Cross-Platform (iOS, Android) apps using one Programming Language and one Codebase.

More formally, Flutter is Google's open-source UI toolkit for building beautiful, natively compiled applications for mobile, web, desktop, and embedded devices from a single codebase.

Native

  • Built with platform-specific languages — Swift for iOS, Java/Kotlin for Android
  • Tight integration with platform hardware & features
  • Smooth performance and full device capability access

Cross-Platform

  • One codebase runs on multiple platforms
  • Saves time & resources
  • Flutter uses Dart, compiled to native code for each platform
In Easy Words Flutter is like a Universal Charger — one thing that works everywhere. It acts as a translator that knows Java/Kotlin (Android) and Swift (iOS), so you write once in Dart and it speaks to both.

Programming Language vs Codebase

Programming Language

The set of rules you use to tell the computer what to build. Like specific instructions: "Dig a moat here, build a tall tower there." It's the language the computer understands.

Codebase

Your entire plan — like a kitchen book with all recipes. It holds all the code for your app in one place, organized in order.

02 Major Components of Flutter

Flutter = two major things:

Flutter SDK

  • Collection of tools to build apps for Android & iOS in one codebase
  • Set of instructions that aid application development
  • Includes tools for converting Dart code to native machine code
  • Works for both iOS and Android

Flutter Framework

  • Provides predefined widgets & widget library
  • Utility functions & packages
  • Set of reusable UI components (buttons, text inputs, sliders, etc.)
  • Components can be customized according to purpose

04 Dart Environment Setup

Follow these steps to set up Dart on Windows:

1
Install the Dart SDK from the official website (dart.dev/get-archive) or use the community Windows installer. Choose the Stable channel x64 version.
2
Download the 64-bit version of the SDK for your OS.
3
Extract the ZIP file and place the dart-sdk folder on any drive other than C: (e.g., D:\Dart SDK\dart-sdk).
4
Open the dart-sdk\bin folder and copy the full path from the address bar.
5
Search ENV in the Windows search bar and open Edit the system environment variables.
6
In System Properties, click Environment Variables.
7
In the Environment Variables window, find the Path variable under User variables and click Edit.
8
In the Edit Environment Variable window, click New.
9
Paste the path you copied in Step 4 and click OK.
10
Open Command Prompt and type dart then press Enter. If you see Dart usage info, the environment is set correctly.
Important Note If typing dart in CMD doesn't work after closing and reopening CMD, it doesn't mean your environment is broken. Navigate to the bin folder manually using CMD commands and type dart from there.

07 Dart Comments

Comments are statements not executed by the compiler. They provide documentation and improve code readability for you and other programmers.

1. Single Line Comment

Starts with // — comments out everything until the end of that line.

int main() {
  double area = 3.14 * 4 * 4;
  // It prints the area
  // of a circle of radius = 4
  print(area);
  return 0;
}DART

2. Multi-Line Comment

Starts with /* and ends with */ — comments out an entire block of code.

int main() {
  double area = 3.14 * 4 * 4;
  /* It prints the area
     of a circle of radius = 4 */
  print(area);
  return 0;
}DART

3. Documentation Comment

Uses /// syntax. Special comments used to generate documentation from the code. Can be associated with classes, methods, functions, and variables. Once written, Dart reuses them automatically.

/// Calculates the sum of two numbers.
///
/// [a] and [b] are the numbers to be added.
///
/// Returns the sum of [a] and [b].
int sum(int a, int b) {
  return a + b;
}DART

01 What is a Variable?

A variable is a named storage location that holds a value. Think of it as a container or a box where you can store information. Variables are used to store and manipulate data in your Dart programs.

Syntax

type variable1, variable2, variable3;  // multiple variables of same typeDART

int

double
Decimal numbers e.g. 9.9, 3.14
String

bool
true or false only
List
Ordered collection of values
Map
Key-value pairs

Example

int main() {

  print(txt);

  int t = 8;

  double d = 8;

04 Dynamic Type Variable

The dynamic type can hold values of any type and its type can change at runtime. When you declare a variable as dynamic, Dart allows assigning different types during execution.

dynamic variable_name;  // syntaxDART
int main() {
  dynamic data = "Pakistan";  // String
  data = 10;                   // Integer — OK
  data = "Hello";              // String again — OK
  data = true;                  // Boolean — OK
  print(data);
  return 0;
}DART

05 VAR Type Variable

The var keyword declares variables without explicitly specifying their type. Dart infers the type from the value assigned at initialization. It provides flexibility while maintaining static typing.

var variable_name;  // syntaxDART
int main() {
  var data;
  data = 2;
  data = "Hello Pakistan";
  data = 9.9;
  print(data);
  return 0;
}DART
Important Points — dynamic vs var
  • If declared as dynamic → type can change anytime during execution.
  • If declared as var (without initialization) → type can change during execution.
  • If declared as var with a double value → type can only change to int.
  • If declared as var with an int or any fixed type → type cannot change to any other type.
// var initialized with double — only int is acceptable after
int main() {
  var data = 9.3;
  data = 2;               // OK (int)
  data = "Hello Pakistan"; // Error!
  data = 9.9;              // OK (double)
  data = false;            // Error!
  data = [1, 2, 3];       // Error!
  return 0;
}DART

1. Arithmetic Operators

Binary operators — act on two operands to perform arithmetic operations.

SymbolNameDescription

-SubtractionSubtract two operands

*MultiplyMultiply two operands
/DivisionDivide two operands — output is double
~/Integer DivisionDivide two operands — output is int

void main() {
  int a = 2, b = 3;
  var c = a + b;  print("Sum: $c");
  var d = a - b;  print("Difference: $d");

}DART

4. Bitwise Operators

Perform bitwise operations directly on the binary representation of integers.

SymbolNameDescription
&Bitwise ANDPerforms AND on each bit of two operands
|Bitwise ORPerforms OR on each bit of two operands
^Bitwise XORPerforms XOR on each bit of two operands
~Bitwise NOTInverts all bits of the operand
<<Left ShiftShifts bits to the left by b positions, inserts 0 from right
>>Right ShiftShifts bits to the right by b positions, inserts 0 from left
 
void main() {
  int a = 5, b = 7;
  print(a & b);   // Bitwise AND
  print(a | b);   // Bitwise OR
  print(a ^ b);   // Bitwise XOR
  print(~a);      // Bitwise NOT
  print(a << b);  // Left Shift: 101(a) moved 7 bits left
  print(a >> b);  // Right Shift
}DART

5. Assignment Operators

Used to assign values to variables.

SymbolNameDescription
=Equal ToAssign a value to a variable
??=Null-aware AssignmentAssign value only if variable is null
 
void main() {
  int a = 5, b = 7;
  var c = a * b;
  print(c);           // 35

  var d;
  d ??= a + b;        // d is null, so assigned = 12
  print(d);           // 12

  d ??= a - b;        // d is NOT null, NOT reassigned
  print(d);           // still 12
}DART

6. Logical Operators

Used to logically combine two or more conditions.

SymbolNameDescription
&&ANDReturns true if both conditions are true
||ORReturns true if at least one condition is true
!NOTReverses the result of a condition
 
void main() {
  int a = 5, b = 7;
  bool c = a > 10 && b < 10;  // AND — false (a is not > 10)
  print(c);
  bool d = a > 10 || b < 10;  // OR — true (b < 10)
  print(d);
  bool e = !(a > 10);          // NOT — true
  print(e);
}DART

7. Conditional Operators

SymbolNameDescription
condition ? expr1 : expr2 Ternary Operator If condition is true → execute expr1, else → execute expr2
expr1 ?? expr2 Null-coalescing If expr1 is non-null → return its value, else → return expr2 
void main() {
  int a = 5;
  // Ternary
  var c = (a < 10) ? "The University of Lahore" : "Information Eng. Tech";
  print(c);  // "The University of Lahore"

  // Null-aware
  int? n;    // nullable int, holds null
  var d = n ?? "n has Null value";
  print(d);  // "n has Null value"

  var t = 2 ?? "Pakistan";
  print(t);  // 2 (non-null, so returns itself)
}DART

8. Cascade Notation Operator

Allows performing a sequence of operations on the same object. Instead of calling multiple methods one-by-one, you chain them with ...

SymbolNameDescription
..Cascading MethodPerform multiple methods on the same object
 
class test {
  var a, b;
  void set(x, y) { this.a = x; this.b = y; }
  void add() { print(this.a + this.b); }
}

void main() {
  test geek1 = new test();
  // Without cascade:
  geek1.set(1, 2);
  geek1.add();

  test geek2 = new test();
  // With cascade notation:
  geek2
    ..set(3, 4)
    ..add();
}DART
